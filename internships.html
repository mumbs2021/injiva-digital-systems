01

Software Engineering

Turn a user need into a maintainable application.

Enquire about this pathway ↗

SKILLS TO DEVELOP

Programming fundamentals; HTML, CSS and JavaScript; Git; debugging; testing; documentation.

ILLUSTRATIVE PROJECT

A small issue-tracking application with validation, a test checklist and clear setup instructions.

Evidence of progress: A working prototype, readable source code, test evidence and a concise handover.

How to prepare

Explain a small program you have written, how you debugged it and what you would improve. This is preparation guidance; formal entry requirements are confirmed for each opportunity.

02

Data Engineering

Make data dependable before it reaches a dashboard or model.

Enquire about this pathway ↗

SKILLS TO DEVELOP

Python and SQL; relational modelling; ingestion; transformations; quality checks; repeatable pipelines.

ILLUSTRATIVE PROJECT

A pipeline that imports sample orders, checks duplicates and missing values, and produces a documented reporting dataset.

Evidence of progress: A documented data model, repeatable pipeline, validation results and recovery notes.

How to prepare

Practise joins, grouping and basic Python file handling; be ready to explain the structure of a small dataset. This is preparation guidance; formal entry requirements are confirmed for each opportunity.

03

Data Analytics

Turn a well-defined question into an evidence-based decision.

Enquire about this pathway ↗

SKILLS TO DEVELOP

Spreadsheets; SQL; data cleaning; descriptive statistics; visualisation; interpretation; communicating limitations.

ILLUSTRATIVE PROJECT

An operational dashboard using synthetic sales data, with metric definitions and a short decision brief.

Evidence of progress: A reproducible analysis, metric dictionary, clear visuals and recommendations with caveats.

How to prepare

Bring a question you have explored with data and explain how you checked the calculations. This is preparation guidance; formal entry requirements are confirmed for each opportunity.

04

AI Engineering

Evaluate intelligent systems before putting them to work.

Enquire about this pathway ↗

SKILLS TO DEVELOP

Python; data preparation; model baselines; evaluation; error analysis; AI workflow design; human review.

ILLUSTRATIVE PROJECT

A bounded document-classification experiment using permitted sample data, comparing a simple baseline with a model.

Evidence of progress: An evaluation dataset, baseline comparison, error analysis and documented operating limits.

How to prepare

Build confidence with Python and basic statistics; be prepared to discuss where a model could be wrong. This is preparation guidance; formal entry requirements are confirmed for each opportunity.
